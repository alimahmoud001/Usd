# محفظة الشبكات المتعددة

هذا المستودع يحتوي على تطبيق HTML واحد لمحفظة غير وصائية. افتح `index.html` مباشرة أو شغّله عبر خادم ملفات ثابت، وسيتم تحميل `ethers.js` وQR من CDN.

## الوظائف الحالية

يدعم التطبيق إنشاء محفظة جديدة بعبارة استرداد من 24 كلمة، واستيراد مفتاح خاص أو عبارة استرداد، مع باسفراز اختياري، وإنشاء محفظة توقيع، ومحفظة مشاهدة بالعنوان العام فقط. تُشفّر المحافظ المملوكة محليًا باستخدام JSON المشفّر من ethers وتُخزّن في `localStorage`، ولا تُرسل المفاتيح أو العبارات إلى الخادم. كما يدعم عرض الأرصدة، والاستقبال عبر العنوان وQR، وتكوين معاملات غير موقعة، والتوقيع والبث المحلي للمحفظة المباشرة بعد طلب كلمة السر، أو البث الخارجي للمعاملات الموقعة.

الإصدار الحالي يربط قراءة الأرصدة وعقود USDT/USDC للشبكات التي توجد لها عناوين عقود موثقة في إعدادات الصفحة: Ethereum، وBNB Smart Chain، وPolygon PoS، وAvalanche C-Chain، وBase. تم حذف مفاتيح Infura وEtherscan الصريحة من الواجهة؛ لا تضع مفاتيح حقيقية داخل HTML عام. يمكن إضافة مفتاح مستكشف عبر خادم وسيط آمن في مرحلة لاحقة.

## تشغيل محلي

```bash
python3 -m http.server 4173
# ثم افتح http://127.0.0.1:4173/index.html
```

قبل استخدام أموال حقيقية، راجع الكود، اختبر على شبكة اختبارية، وتحقق من العنوان والشبكة والكمية ورسوم الغاز. احتفظ بعبارة الاسترداد خارج الجهاز، ولا تستخدم التخزين المحلي كنسخة احتياطية وحيدة.
